# SlagReference
Учебная справочная система состава и температурных характеристик доменных шлаков.

Стек: C#, ASP.NET Core MVC (.NET 9), EF Core, MariaDB 11.4, Docker Compose, GitHub Actions, GHCR.

## Запуск
1. Скопируйте `.env.example` в `.env`.
2. Задайте собственные пароли в `.env`.
3. Выполните `docker compose up -d --build`.
4. Откройте http://localhost:5080

При первом запуске создаётся схема БД и тестовые записи. Они демонстрационные, не нормативные металлургические данные. Заменяйте их данными из проверенных источников.

Основные функции: CRUD составов, проверка суммы компонентов 100%, поиск составов, температурные записи, справочник оксидов.

GitHub Actions собирает Docker-образ и публикует его в GHCR при push в main.
